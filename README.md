# sorting-algorithms

WebApp to demonstrate various sorting algorithms

View the WebApp [here](https://samuel-risner.github.io/sorting-algorithms/)

# Dev notes

## Installing development dependencies

```sh
npm i -D
```

## Running dev server

```sh
npm run dev
```

## Building web app

```sh
npm run build
```

Make sure that the folder in `vite.config.ts` is correct
